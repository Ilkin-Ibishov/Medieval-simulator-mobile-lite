# UI/UX Designer Skill

## 1. Master Atlas Cartography Standards
1. **Dərin Prussiya Dənizi:** Radial gradient (`#141f2b` → `#0f1721` → `#080c10`) və Portolan koordinat naviqasiya toru (`rgba(85, 135, 180, 0.06)`).
2. **Sahilyanı Su Qabarması (Coastal Waterline Ripples):** İkiqat su zolağı halo qatı (`#1e3448` & `#325370`).
3. **Dinamik Dövlət Başlıqları (Floating Titles):** Xəritə sahə payına görə nisbi miqyas (`fontSize: 12 + sqrt(ratio) * 38`) və BFS Largest Connected Cluster Centroid yerləşməsi.
4. **Smart Mobil Auto-Focus:** Başlanğıcda oyunçunun krallığına fokuslanma (`zoom: 1.45`), `👑` və `🌍` sürətli keçid çipləri.
5. **İstehkam Nişanları:** Əyalətdə tikilmiş Qala (`🏰`) və Qüllə (`🗼`) SVG heraldik möhürləri.
