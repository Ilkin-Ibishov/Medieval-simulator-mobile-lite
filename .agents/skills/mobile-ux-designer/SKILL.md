# Mobile UX Designer Skill

## 1. Performance & Touch Ergonomics
* **GPU Hardware Acceleration:** Gesture zamanı React re-render-ləri aradan qaldırılıb, birbaşa DOM `style.transform = translate3d(...) scale(...)` tətbiq olunur.
* **Layout Containment:** `.map-svg` və `.map-transform-layer` daxilində `contain: layout paint size` və `will-change: transform`.
* **Thumb Zone ActionHUD:** Ekranın aşağısında bir əllə idarə olunan sürətli yığım, tərxis, ordu slider-i və istehkam düymələri.
